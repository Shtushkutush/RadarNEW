# RADAR GREEN 2.2 — температура воздуха

Вместо подписи STEP на минутной точке теперь отображается температура на улице:
`OUT +12C`, `OUT -5C` или `OUT --`, если значение ещё не получено.

- Погода: Open-Meteo, параметр current.temperature_2m, градусы Цельсия.
- Только при подключении к интернету; без сети приложение не делает погодных запросов.
- После успешного обновления повторная загрузка не раньше чем через 1 час.
- При ошибке повторная попытка не чаще чем через 15 минут, если приложение активно и сеть есть.
- Последняя температура сохраняется локально и видна без интернета.
- Местоположение: требуется разрешение Android. Первый раз открой приложение и разреши доступ.
- Местоположение используется для выбора погодной точки; часы должны предоставлять провайдер GPS/Network.
- Погодные запросы выполняются в фоне, данные обновляются пока циферблат виден.
- Штатный STEP не нужен; BAT остаётся у часовой точки.
- Сохранены дневной / ночной стиль и умный Always-On через 15 секунд.

## Ограничения

Это режим Always-On **внутри активного приложения или видимых живых обоев**.
Он не способен отменить системное отключение дисплея Android, если прошивка LOKMAT
выключает экран. Приложение не запрашивает wakelock и не удерживает экран включённым.

При первом запуске может быть `OUT --`, пока часы не определят местоположение и
не получат ответ сервиса. Если геолокация на часах отключена или не предоставлена,
автоматическая погода недоступна.

На 400×400 матричный шрифт отображает `C` вместо символа градуса для устойчивой
читаемости (например, `OUT +12C`).

## Сборка

Загрузить **содержимое** этой папки в корень GitHub-репозитория и открыть Actions →
Build Radar Green APK. На GitHub Runner нужна поддержка Android SDK.

Из-за возможного конфликта подписи с предыдущим debug APK может потребоваться
удалить предыдущую версию перед установкой.

Погодные данные: Open-Meteo (https://open-meteo.com/).

# RADAR GREEN 2.0 — LOKMAT APPLLP 6 (Android 9)

Новое обновление исходного циферблата под круглый экран 400 × 400.

## Новое
- Часовая точка на внутренней орбите с движущейся подписью `BAT 86%` — **реальный процент аккумулятора**.
- Минутная точка на внешней орбите с движущейся подписью `STEP 8427` — **данные датчика шагов Android**, если датчик TYPE_STEP_COUNTER поддерживается часами.
- Тексты рисуются настоящими точками 5×7, а не шрифтом с размытием.
- При пересечении сканирующего луча точка и её подпись слегка светлеют, затем постепенно тускнеют. Дневное затухание 1.5 с, ночное 2 с. Вспышек и сильного неона нет.
- Автоматический день: 07:00–21:59; ночь: 22:00–06:59 по локальному времени часов.
- Приложение не блокирует выключение экрана, частота обновления приблизительно 20 FPS, при паузе приложения / скрытых живых обоях кадры не рисуются.
- Никаких рекламных SDK, интернета или сторонних библиотек приложения.

## Важно про шаги
Android TYPE_STEP_COUNTER возвращает *общее число шагов с последней перезагрузки*, а не «сегодня».
Для простого автономного подсчёта программа сохраняет первое значение датчика за текущий день и отображает разницу.
Поэтому после первой установки / первого открытия за день число шагов может начинаться с нуля, а не совпадать с фирменным шагомером LOKMAT. Если датчик отсутствует или недоступен, на экране будет `STEP --`. Данные не выдумываются. Для точной синхронизации с заводским шагомером понадобится его документированный интерфейс либо иной источник данных.

## Установка обновления поверх 1.0
Пакет `com.radargreen.watch` сохранён. Версия повышена с 1 до 2.
GitHub Action выдаёт **debug APK**, подписанный отладочным ключом GitHub Runner. Если предыдущее приложение было подписано другим отладочным ключом (обычно так и бывает), Android сообщит «Приложение не установлено» или конфликт подписи. В таком случае удалите старый Radar Green и установите новый APK; личные данные шагов внутри приложения будут сброшены.

## Как собрать через GitHub (без Android Studio)
1. В своём репозитории замените файлы проекта содержимым **внутренней папки** `RadarGreen_2_0` из этого архива. Не создавайте дополнительный вложенный каталог.
2. В папке `.github/workflows/` должен быть один файл сборки (можно удалить прежний `build.yml`, чтобы не запускать два workflow одновременно).
3. Откройте Actions → Build Radar Green APK → Run workflow или дождитесь автоматической сборки после commit.
4. После успешной сборки скачайте артефакт **RadarGreen-2.0-APK**, распакуйте и установите `app-debug.apk` на часы.

Обратите внимание: приложение запускается в полноэкранном режиме либо как живые обои (если поддерживает прошивка); не обязательно заменяет заводской циферблат. Ночной режим меняет яркость *рисунка*, но физическую подсветку IPS-экрана регулируют системные настройки.

## Исправление AOD (2.2.1)
В полноэкранном приложении добавлен `FLAG_KEEP_SCREEN_ON`: Android не должен выключать экран по обычному тайм-ауту, пока Activity видна. Через 15 секунд интерфейс становится статичным, а яркость экрана запрашивается на уровне 3.5%; касание возвращает системную яркость и плавный сканер. Конкретная прошивка может ограничивать минимальную яркость или принудительно выключать дисплей. При нажатии кнопки питания, сворачивании приложения или в режиме живых обоев этот флаг не удерживает экран. Постоянно включённый IPS-дисплей увеличит расход батареи. Погода требует геолокации и интернета; в этой версии её источник не изменялся.
